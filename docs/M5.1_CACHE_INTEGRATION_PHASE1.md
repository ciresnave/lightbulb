# M5.1 Cache Management Integration - Phase 1 Implementation

## Overview
Added architecture-aware capabilities to the `ParallelCacheBuilder` to enable automatic detection of layer count and model architecture. This provides foundation for future architecture-specific cache optimizations.

## Implementation Date
January 2026 (same day as M4.1!)

## Changes Made

### 1. Added Name Mapper Support to ParallelCacheBuilder

**File**: `src/cache/parallel_cache_builder.rs`

Added optional `TensorNameMapper` field:
```rust
#[derive(Debug)]
pub struct ParallelCacheBuilder {
    // ... existing fields ...
    /// Optional name mapper for architecture-aware operations (M5.1)
    /// Enables automatic detection of layer count and architecture-specific optimizations
    name_mapper: Option<std::sync::Arc<crate::pruning::name_mapping::TensorNameMapper>>,
}
```

**Why Arc?** Enables zero-cost sharing of name mapper across multiple components (cache, model, pruning, etc.)

### 2. New Helper Methods

Added three new methods to ParallelCacheBuilder:

#### `set_name_mapper()`
```rust
pub fn set_name_mapper(
    &mut self,
    mapper: Option<Arc<TensorNameMapper>>,
)
```
- Sets the name mapper for architecture-aware operations
- Shares the mapper efficiently via Arc

#### `detected_layer_count()`
```rust
pub fn detected_layer_count(&self) -> Option<usize>
```
- Returns number of layers detected from model architecture
- Useful for sizing per-layer caches correctly
- Returns `None` if no name mapper set

#### `detected_architecture()`
```rust
pub fn detected_architecture(&self) -> Option<&ModelArchitecture>
```
- Returns detected architecture (LLaMA, GPT, Mistral, Unknown)
- Enables architecture-specific optimizations in cache management

### 3. Debug Trait Addition

**File**: `src/pruning/name_mapping.rs`

Added `#[derive(Debug)]` to support structs:
```rust
#[derive(Debug)]
pub struct TensorNameMapper {
    // ...
}

#[derive(Debug)]
struct ArchitecturePatterns {
    // ...
}
```

Required for `ParallelCacheBuilder` to derive Debug.

## Usage Example

```rust
use std::sync::Arc;
use lightbulb::pruning::name_mapping::TensorNameMapper;
use lightbulb::cache::ParallelCacheBuilder;

// Load model and get tensor names
let tensor_names: Vec<String> = gguf_content
    .tensor_infos()
    .keys()
    .cloned()
    .collect();

// Build name mapper
let name_mapper = TensorNameMapper::from_tensor_names(&tensor_names)?;
let mapper_arc = Arc::new(name_mapper);

// Create cache builder
let mut cache_builder = ParallelCacheBuilder::new(
    batch_size,
    context_length,
    DType::F32,
    &device,
)?;

// Enable architecture-aware features
cache_builder.set_name_mapper(Some(mapper_arc));

// Query architecture info
if let Some(num_layers) = cache_builder.detected_layer_count() {
    println!("Model has {} layers", num_layers);
    
    // Could size per-layer caches dynamically:
    let mut layer_caches = Vec::with_capacity(num_layers);
    for _ in 0..num_layers {
        layer_caches.push(cache_builder.make_cache(num_heads, head_dim)?);
    }
}

if let Some(arch) = cache_builder.detected_architecture() {
    println!("Architecture: {:?}", arch);
    // Could apply architecture-specific optimizations
}
```
