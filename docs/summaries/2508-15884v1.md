
# 2508.15884v1 — Quantization + Blocked-Sparsity Interactions

TL;DR

- Empirical study on how low-bit quantization interacts with blocked-sparsity patterns and its effect on accuracy and throughput. Focused experiments measuring how quantization interacts with blocked sparsity and proposes mitigation strategies.

Why it matters

- Practical for building CPU-efficient kernels: combined techniques can multiply benefits but also introduce coupling effects that break naive pipelines.
- Guides design choices when combining quantized kernels and blocked-sparsity for CPU inference in lightbulb.

Key takeaways

- Calibration per-block reduces accuracy loss; mixed-precision accumulation recovers some errors.
- Authors recommend an empirical tuning loop when deploying combined optimizations.

Actions / Implementation steps for lightbulb

1. Add per-block calibration and a mixed-precision accumulation option to the blocked-sparsity kernel.
2. Run a lightweight tuning sweep to generate recommended defaults for target CPUs.
3. Add unit tests for quantized blocked-sparse matmul kernels and measure accuracy drop across bitwidths and block sizes.

Acceptance criteria

- End-to-end accuracy drop remains under acceptable threshold (configurable), and perf improves relative to baseline.
- Identify a safe operating point (bitwidth + block size) where accuracy loss <=1% and throughput improves by >=30%.
