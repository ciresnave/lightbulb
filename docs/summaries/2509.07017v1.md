TL;DR

2509.07017v1 explores low-latency quantized kernels for CPU inference, focusing on cache-friendly layout and int8 GEMM optimizations.

Why it matters

- High impact for CPU-only throughput and memory-limited deployments.

Actions

1. Prototype quantized GEMM layout optimizations in `kernels.rs` and add microbenchmarks.
2. Add documentation describing memory layout tradeoffs for int8 kernels.

Acceptance criteria

- Microbenchmarks showing measurable throughput gains on common CPU targets with stable numerical behavior.
