# 2509.01092v1 — Continual learning with replay buffers

TL;DR

- Explores replay-buffer strategies for continual adaptation without catastrophic forgetting, including buffer sampling policies.

Why it matters

- Informs online-adaptation features for model updates during long-running services while preserving past performance.

Actions

- Prototype a small replay buffer API in `cache.rs` or `loaders.rs` and test simple sampling/priority policies.
- Evaluate on streaming tasks to measure stability vs. adaptation speed.

Acceptance criteria

- Demonstrate stable adaptation with negligible regression on prior distributions for at least one streaming benchmark.
