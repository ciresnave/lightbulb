# 2509.13310v1 — Reproducible CPU latency/throughput benchmarks (note)

TL;DR

- Prescribes practices for reproducible CPU benchmarking (thread pinning, warmup, pinned affinities, deterministic workloads) and offers a reference harness.

Why it matters

- Reproducible CPU benchmarks are critical for validating kernel and scheduler improvements in a CPU-first project like lightbulb and for CI regression checks.

Actions

- Add a small Windows-compatible microbenchmark harness following the paper's guidance (pin threads, fixed CPU frequency, warmup iterations).
- Add a CI job that runs the harness on our Windows CI runner and records standardized JSON outputs for comparisons.

Acceptance criteria

- Microbenchmark produces <5% variance across repeated runs on the same machine and produces comparable results across two representative CI machines.
