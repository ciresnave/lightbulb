# 2506.04761v2 — Adaptive Layer Selection / Shallow-then-Deep

TL;DR
Explores adaptive depth strategies that route tokens through fewer layers when confident, using a shallow-then-deep heuristic and lightweight confidence estimators to save compute.

Why it matters

- Adaptive depth can substantially reduce average compute per token for many workloads and pairs well with our scheduler and verifier to maintain output quality.

Actions

- Add an early-exit policy prototype to the scheduler with per-layer confidence checks and minimal overhead estimators.
- Evaluate average FLOPs/token reduction vs baseline and measure accuracy/perplexity tradeoffs.

Acceptance criteria

- Demonstrate >=20% FLOPs/token reduction with less than 1% increase in task error on a set of representative validation tasks.
