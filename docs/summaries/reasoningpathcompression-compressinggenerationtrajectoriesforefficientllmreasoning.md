## TL;DR

This paper introduces Reasoning Path Compression (RPC), a training-free method to accelerate inference in reasoning-focused LLMs by compressing the key-value (KV) cache. RPC leverages semantic sparsity in reasoning paths to retain only important tokens, improving throughput and memory efficiency with minimal accuracy loss.

## Why it matters for Candle (Rust ML library)

Candle users can use RPC to deploy reasoning LLMs more efficiently, reducing memory and compute requirements for long reasoning sequences. Integrating RPC supports scalable, practical deployment of advanced reasoning models.

## Key technical takeaways

- Reasoning LLMs generate lengthy intermediate reasoning paths, increasing KV cache overhead and slowing inference.
- Reasoning paths exhibit semantic sparsity: many steps are redundant or revisited, allowing selective compression.
- RPC periodically compresses the KV cache, retaining only high-importance tokens based on attention scores.
- Achieves up to 1.6x throughput improvement and 75% KV cache reduction with minimal accuracy drop (1.2% on AIME 2024).
- RPC is training-free and compatible with existing reasoning LLMs.
