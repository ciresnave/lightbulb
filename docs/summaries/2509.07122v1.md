# 2509.07122v1 — Adaptive per-token/per-layer sparsity predictor

TL;DR

- Proposes lightweight predictors that estimate sparsity needs per-token and per-layer to enable dynamic sparsity during inference.

Why it matters

- Can reduce compute by dynamically skipping work where sparsity is high, useful for token-adaptive inference and MoE-style routing.

Actions

- Prototype a predictor hook that computes a cheap sparsity score per token and informs a per-layer mask during forward pass.
- Measure end-to-end throughput and accuracy trade-offs on representative sequences.

Acceptance criteria

- Achieve >=10% compute reduction on average tokens with <1% downstream accuracy loss on benchmark tasks.
