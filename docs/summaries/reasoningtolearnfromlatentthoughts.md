## TL;DR

This paper proposes a paradigm for data-efficient language model (LM) pretraining by inferring and modeling latent thoughts underlying text. Augmenting training data with synthesized latent thoughts improves reasoning and learning efficiency, especially in data-constrained regimes, and enables iterative self-improvement via bootstrapping.

## Why it matters for Candle (Rust ML library)

Candle users can leverage latent thought augmentation to train LMs more efficiently, extracting greater capabilities from limited data. Integrating this approach supports scalable, high-performance model development even when data is scarce.

## Key technical takeaways

- Human-written text is a compressed outcome of verbose thought processes; inferring latent thoughts can improve LM training.
- Augmenting data with latent thoughts (via synthetic generation or EM bootstrapping) significantly boosts data efficiency and reasoning performance.
- Bootstrapping Latent Thoughts (BoLT) enables iterative self-improvement, with increasing gains from additional inference compute and EM iterations.
- Demonstrated 5.7% → 25.4% improvement on MATH benchmark using latent thought augmentation.
- Approach is compatible with existing LMs and requires minimal changes to standard pretraining pipelines.
