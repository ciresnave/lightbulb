# 2506.15882v1 — Verifier & reasoning checks

TL;DR

- Proposes lightweight verifier tests and heuristics to detect invalid or low-quality model generations early in the sampling process.

Why it matters

- Direct inspiration for the `Verifier` component in lightbulb's sampling pipeline; can save compute by early-aborting bad trajectories.

Actions

- Implement a small library of symbolic and numeric verifier checks and expose hooks in `sampling.rs`.
- Add benchmarks to measure compute saved vs. false-rejection rate across reasoning datasets.

Acceptance criteria

- Verifier reduces wasted sampling compute by >=10% while keeping task-level accuracy within 1% of baseline.
