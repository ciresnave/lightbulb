# 2506.23293v1

TL;DR

This work studies latency-robust attention implementations designed to avoid worst-case quadratic spikes by early-detection of high-cost patterns and applying bounded approximate kernels.

Why it matters for lightbulb

- Valuable for our CPU-first path: provides heuristics to detect and mitigate expensive attention patterns at runtime via `Scheduler` decisions.

Actions

1. Implement a simple attention-cost estimator that runs in O(n) to decide whether to switch kernels.
2. Add a `Scheduler` hook that can swap to an approximate kernel when estimated cost > threshold.

Acceptance criteria

- Attention-cost estimator API added with tests, and a benchmark showing switching reduces worst-case latency spikes by ≥30% on synthetic adversarial inputs.
