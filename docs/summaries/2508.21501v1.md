# 2508.21501v1 — Verification-first sampling methods

TL;DR

- Introduces a verification-first sampling approach: run cheap checks early in sampling to avoid expensive continuation of invalid trajectories.

Why it matters

- Directly applicable to our Verifier design and can reduce wasted compute during sampling-heavy workloads.

Actions

- Prototype verifier hooks in sampling.rs that can be toggled per-model or per-request.
- Measure compute savings and impact on final output quality across reasoning benchmarks.

Acceptance criteria

- End-to-end sampling pipelines using verifier hooks save >=15% compute while keeping output accuracy within 1% of baseline.
