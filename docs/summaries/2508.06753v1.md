# 2508.06753v1 — Small-model CPU variants survey

TL;DR

- Survey of CPU-optimized model variants and microarchitectural techniques for efficient small-model inference on commodity hardware.

Why it matters

- Shows practical kernel and memory-layout strategies we can adopt for CPU-first deployment and deterministic CI testing.

Actions

- Prototype a small-model build target (reduced hidden dims / fused kernels) for Candle-backed inference.
- Benchmark memory layout and blocking strategies on representative CPU cores.

Acceptance criteria

- A microbenchmark demonstrating >=15% throughput improvement on target CPU for a small LM compared to baseline implementation.
