# 2509.26507v1

TL;DR

Presents methods for reproducible CPU benchmark harnesses, including pinned-thread scheduling, isolation of OS noise, and deterministic random seeds.

Why it matters

- Our objective to provide reproducible CPU latency/throughput benchmarks for `lightbulb` can adopt these best practices to make CI measurements stable.

Actions

- Add a benchmarking helper module (`benches/reproducible.rs`) applying pinned threads and seed controls for microbenchmarks.
- Document recommended CI runner settings in `docs/benchmarks.md`.

Acceptance criteria

- Microbenchmarks show <5% run-to-run variance across 5 runs on the same machine with the helper enabled.
