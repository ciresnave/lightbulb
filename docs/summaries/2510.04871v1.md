# 2510.04871v1 — Int4/Int8 mixed-precision kernel benchmarks (alternate)

TL;DR

- Benchmarks and analysis focusing on mixed int4/int8 kernels with practical profiling guidance for layer-wise bitwidth selection and safe operating points.

Why it matters

- Gives actionable guidance for building mixed-precision kernels and a profiler to choose per-layer bitwidths to maximize throughput while preserving accuracy.

Actions

- Implement a simple profiler that measures accuracy vs. throughput trade-offs per layer and outputs recommended bitwidth settings.
- Integrate a runtime switcher that can apply recommended per-layer settings during model load.

Acceptance criteria

- A profiling tool that outputs per-layer bitwidth recommendations and demonstrates throughput improvements with <=1% accuracy loss on representative models.
