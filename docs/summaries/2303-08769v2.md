
# 2303.08769v2 — Calibration & Robustness (short paper)

TL;DR

The paper presents lightweight, practical calibration techniques (notably post-hoc temperature scaling) and an OOD evaluation harness. It demonstrates that simple calibration reduces expected calibration error (ECE) and that OOD evaluations catch common failure modes relevant to downstream decision systems.

Why it matters for Lightbulb

- Lightbulb's scheduler, verifier, and early-exit mechanisms depend on reliable confidence estimates. Calibration reduces false positives for deep computation (avoids wasted compute) and improves gating decisions for conditional compute.
- Calibration affects downstream decision-making, especially when sampling or early-exit decisions rely on confidence scores.
- The paper provides practical evaluation recipes that translate directly into safer sampling and verifier thresholds for inference systems.

Key technical takeaways

1. Post-hoc temperature scaling is an inexpensive, effective baseline for improving calibration across a variety of models and datasets.
2. Ensemble or moving-average logit aggregation reduces variance and improves out-of-distribution confidence estimates.
3. Calibration should be measured under realistic shifts (synthetic distribution shifts, domain holdouts) — in-distribution numbers are often misleading.
4. Simple data augmentations (masking/noising) used at calibration time can increase robustness with negligible compute cost.

Actions / Implementation steps for lightbulb

1. Implement `sampling::calibrate_temperature(logits, labels)` which fits temperature via negative log-likelihood on a held-out calibration set and returns a calibrated-scorer wrapper.
2. Add an OOD/robustness harness under `tests/robustness/` that: (a) generates simple perturbations (noise, token dropout), (b) computes ECE/AUROC, and (c) compares raw vs calibrated scores.
3. Wire a small CLI example (dev-only) `cargo run -p lightbulb -- calibrate --model-dir <path> --calib-set <file>` that demonstrates the flow on a tiny model.
4. Add a calibration evaluation stage to the sampling pipeline that computes reliability diagrams and expected calibration error (ECE) on validation splits and configurable OOD splits.
5. Implement a lightweight temperature-scaling utility and expose it as a post-processing option in the sampling CLI and API.
6. Provide an optional moving-average logits/ensemble wrapper in the verifier component (configurable window length).
7. Add a small data-augmentation hook (mask/noise) to generate shift-like calibration folds for CI experiments.

Acceptance criteria

- `sampling::calibrate_temperature` added, unit-tested, and documented in `docs/` with a toy example that reduces ECE.
- OOD harness added with a reproducible CI-friendly test that prints ECE/AUROC for raw and calibrated runs.
- OOD harness added under `tests/` with a reproducible example and CI-friendly output.
- Reproduce a reliability diagram for a representative validation set and reduce ECE by >=20% vs the current baseline.
- Temperature-scaling is exposed in the CLI and unit-tested with a small synthetic example.
