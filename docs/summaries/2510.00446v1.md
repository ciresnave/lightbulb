# 2510.00446v1 — Int4/Int8 mixed-precision kernel benchmarks

TL;DR

- Benchmarks and analysis of mixed int4/int8 kernels across layers and operators, with guidance on safe switching points.

Why it matters

- Provides practical mixed-precision strategies for kernel implementations to trade accuracy for throughput on CPU quantized execution.

Actions

- Implement mixed-precision matmul kernels and an automated profiler that recommends layer-wise bitwidth settings.
- Run accuracy and throughput sweeps to determine safe defaults for common model families.

Acceptance criteria

- A profiling script that outputs recommended per-layer bitwidths and demonstrates throughput gains with <=1% accuracy loss.
