# 2507.00951v1 — Kernel fusion optimizations

TL;DR

- Describes techniques for fusing small tensor ops to reduce memory traffic and improve CPU throughput.

Why it matters

- Kernel fusion is a low-risk, high-reward optimization for CPU inference; good for deterministic CI benchmarking.

Actions

- Evaluate candidate fusions (e.g., bias+gelu, matmul+add) and add a small set of fused kernels to `kernels.rs`.
- Add unit tests to verify numerical equivalence and microbenchmarks for throughput.

Acceptance criteria

- Fused kernels show >=10% throughput improvement on representative inference workloads with negligible numerical drift.
