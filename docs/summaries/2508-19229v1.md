## Part 1: Latency-Robust Attention Heuristics for CPU Inference

TL;DR

- Heuristics and transforms to make attention implementations robust to latency spikes and cache effects.

Why it matters

- For small-batch CPU inference, micro-architectural effects can dominate; heuristics that adapt blocking and prefetch help stability.

Key takeaways

- Dynamic block size selection based on recent latency samples helps reduce percentile jitter.
- Feedback from a lightweight profiler can guide prefetch and tiling changes at runtime.

Actions / Implementation steps for lightbulb

1. Add a small profiler to monitor attention kernel latencies and cache metrics.
2. Implement dynamic block-size selection and a conservative fallback when jitter increases.

Acceptance criteria

- Reduced 95th/99th latency variance across representative workloads.
