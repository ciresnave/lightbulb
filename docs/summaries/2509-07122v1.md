# 2509.07122v1 — Adaptive per-token/per-layer sparsity predictor (stub)

TL;DR

- Short summary: a lightweight predictor for adaptive sparsity both per-token and per-layer to reduce compute.

Why it matters

- Predictive sparsity reduces wasted compute and can be applied dynamically to lower the cost of long-context inference.

Key takeaways

- Low-latency predictors can operate with <1ms overhead and still realize meaningful compute savings.
- Combining per-token and per-layer signals yields better results than either alone.

Implementation steps

1. Implement a small predictor interface that ingests token-level and layer-level signals.
2. Add a conservative policy that only applies sparsity when predicted benefit outweighs risk.

Acceptance criteria

- Net compute reduction without measurable accuracy drop on target tasks.
