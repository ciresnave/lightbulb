# 2509.03646v2 — Hybrid LRU-LFU eviction policies for KV stores (stub)

TL;DR

- Short summary: hybrid eviction policies combining recency and frequency for KV caches used in attention caching.

Why it matters

- A good eviction policy keeps hot keys in cache and reduces recompute while keeping memory bounded.

Key takeaways

- A hybrid policy that weights recency and frequency is robust across workloads with varying token reuse patterns.

Implementation steps

1. Implement a small hybrid LRU-LFU eviction policy for the KV cache with lightweight counters.
2. Expose weight parameters and benchmarks to tune them.

Acceptance criteria

- Reduced recompute and improved end-to-end throughput on workloads with locality while bounding memory.
