# 2509.01092v1 — Continual learning with replay buffers (stub)

TL;DR

- Short summary: lightweight continual learning techniques with small replay buffers and periodic rehearsal to preserve long-term performance.

Why it matters

- Models that adapt online risk catastrophic forgetting; small replay buffers plus stable updates mitigate this in low-resource settings.

Key takeaways

- Prioritized replay and small, frequent rehearsal windows perform well for online adaptation.
- Compute-aware rehearsal scheduling avoids interfering with inference tail-latency targets.

Implementation steps

1. Add a simple replay buffer API and a rehearsal scheduler to the runtime.
2. Evaluate stability vs. freshness trade-offs on streaming workloads.

Acceptance criteria

- Reduced forgetting on benchmark streams with bounded additional compute and latency impact.
