# 2508.15126v1 — Scheduler preemption strategies

TL;DR

- Analysis of preemption and priority scheduling strategies for low-latency inference workloads with mixed request sizes.

Why it matters

- Provides algorithms for fair latency-aware preemption useful for the lightbulb request scheduler when running on shared CPUs.

Actions

- Implement a simple token-count-based preemption policy in the scheduler prototype.
- Simulate mixed small/large request workloads and measure tail-latency improvements.

Acceptance criteria

- Scheduler reduces 95th-percentile latency by >=20% in simulated mixed workloads without hurting average throughput by more than 5%.
