TL;DR

Paper 2508.19229v1 proposes a lightweight parameter-efficient fine-tuning approach that reuses adapter modules with runtime pruning to reduce memory footprint during inference.

Why it matters

- Enables low-memory on-device updates and quick deployment for small tasks.
- Suggests pruning schedules that preserve important adapter weights.

Actions

1. Add to the KD/offloading and model-compression research bucket.
2. Implement an adapter-pruning experiment in `tests/` to measure memory vs. accuracy.

Acceptance criteria

- A reproducible script in `examples/` demonstrating adapter pruning with no more than 2% drop on a small text classification dev set.
