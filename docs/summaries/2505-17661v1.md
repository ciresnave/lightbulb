
# 2505.17661v1 — Blocked Sparse-Attention (CPU)

TL;DR

Presents a CPU-optimized blocked sparse-attention kernel that reduces memory traffic and uses cache-friendly blocking to accelerate long-context attention for sparse patterns. This work presents a blocked sparse-attention kernel optimized for CPU vector units and cache hierarchies. By partitioning attention into cache-friendly tiles and exploiting sparsity, the authors report sizable speedups for medium-to-long sequences.

Why it matters for Lightbulb

- A practical blocked sparse-attention kernel can significantly reduce CPU inference latency on long contexts and is directly implementable in `lightbulb`'s kernel layer.
- A production-grade CPU inference path benefits directly from blocked sparse kernels: reduced memory traffic and improved throughput without changing model weights.

Key technical takeaways

1. Blocking attention to fit L1/L2 cache lines reduces memory traffic and improves throughput when sparsity is structured.
2. Sparse-matrix packing and prefetch-aware loops further reduce cache-miss penalties.
3. For CPU targets, careful loop tiling and avoiding dynamic allocation in the hot path are crucial for predictable latency.
4. Combining blocked sparse attention with quantized kernels amplifies throughput gains but requires careful per-layer validation.
