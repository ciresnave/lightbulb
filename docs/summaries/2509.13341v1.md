# 2509.13341v1

TL;DR

Short empirical study introducing cache-aware attention scheduling for CPU-first inference, showing simple blocking heuristics reduce latency on long contexts by up to ~18% without accuracy loss.

Why it matters

- Focuses on CPU-friendly scheduling and blocking strategies — directly applicable to lightbulb's kernel and KV cache designs.
- Demonstrates measurable latency improvements on long-context workloads, which is a key target for our CPU CI path.

Actions

- Prototype the paper's blocking schedule in `kernels.rs` as an opt-in attention scheduler.
- Add a microbenchmark that measures latency on long-context sequences (2560+ tokens) using our CPU runner.

Acceptance criteria

- Implemented scheduler toggled by a feature flag, with a benchmark showing >=10% latency improvement on at least one long-context workload compared to baseline.
