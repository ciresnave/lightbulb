# 2506.22443v1 — Per-layer Sparsity Masks

TL;DR
Describes compact storage formats and runtime application strategies for per-layer sparsity masks, including bit-packing and tile-aligned masks that enable efficient masked kernels.

Why it matters

- Applying sparsity at runtime can cut compute significantly, but naive mask formats add memory and branching overhead; this paper provides low-overhead, tile-aligned approaches.

Key technical takeaways

1. Bit-packed masks plus on-the-fly unpacking can be faster than full dense masks when aligned to compute tiles.
2. Run-length and tile granularity trade-offs: finer tiles give more sparsity but increase mask overhead.
3. Mask-aware kernels should be branch-free and operate on packed tiles for predictable performance.

Implementation steps for lightbulb

- Add a compact mask file format and loader with support for bit-packed and RLE encodings.
- Implement tile-aligned masked kernels and runtime checks to select between dense and masked paths.
- Provide tools to measure mask sparsity distributions and choose tile sizes.

Acceptance criteria

- Show net compute reduction on masked models with <1% accuracy degradation on a validation set.
