# 2510.06557v1

TL;DR

Investigates adaptive per-layer scaling for mixed-precision inference, showing simple heuristics to pick int4/int8 for layers based on activation ranges and sensitivity tests.

Why it matters

- Helps choose per-layer precision profiles for mixed-precision kernels in `kernels.rs` and informs scheduling decisions for precision-aware batching.

Actions

- Implement a small activation-profiling utility in `loaders.rs` to record per-layer ranges and suggest per-layer precisions.
- Add an automated sensitivity test to evaluate accuracy vs. precision choices on a tiny model.

Acceptance criteria

- A profiling run that outputs a per-layer precision recommendation file and a sensitivity report with <2% perplexity drop for the chosen mixed-precision profile.
