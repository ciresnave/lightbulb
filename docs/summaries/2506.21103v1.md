# 2506.21103v1 — Cache-friendly blocking strategies

TL;DR

- Examines blocking and tiling strategies that improve cache locality for attention and GEMM on CPUs.

Why it matters

- Provides practical kernel/layout ideas to improve throughput for small-batch CPU inference in lightbulb.

Actions

- Prototype blocked GEMM/attention kernels in `kernels.rs` and measure cache-miss reductions.
- Test different blocking sizes across representative CPU cores and model dims.

Acceptance criteria

- Achieve >=20% reduction in L1/L2 cache misses and a measurable throughput gain on target microbenchmarks.
