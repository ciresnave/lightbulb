# 2505.17661v1 — Blocked sparse-attention (CPU)

TL;DR

This work presents a blocked sparse-attention kernel optimized for CPU vector units and cache hierarchies. By partitioning attention into cache-friendly tiles and exploiting sparsity, the authors report sizable speedups for medium-to-long sequences.

Why it matters for Lightbulb

- A production-grade CPU inference path benefits directly from blocked sparse kernels: reduced memory traffic and improved throughput without changing model weights.

Actions

1. Implement a toy `kernels::cpu::blocked_sparse_attn` in `bench/` to validate the reported blocking heuristics.
2. Add microbenchmarks measuring throughput, memory bandwidth, and cache-miss counters vs a dense baseline.
3. Draft an API proposal `kernels::BlockedSparseAttention` in `docs/design/kernels.md` for runtime selection.

Acceptance criteria

- Toy prototype in `bench/` with measurable throughput improvements (target >=1.2x for long sequences) and documentation of the blocking heuristics.
- `docs/design/kernels.md` contains an API proposal and a plan for runtime selection/autotuning.
