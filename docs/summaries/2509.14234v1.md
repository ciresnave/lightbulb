# 2509.14234v1

TL;DR

Describes an adaptive quantization calibration procedure that preserves distributional properties across layers and reduces post-quantization drift for int8 inference.

Why it matters

- Better quantization stability reduces surprising accuracy drops when using int8 GEMMs — relevant to our quantized loader and int8 kernel plans.

Actions

- Add the calibration routine as a utility in `loaders.rs` and expose a test harness that compares per-layer activation distributions before/after quantization.

Acceptance criteria

- A reproducible calibration test that shows <1% relative perplexity increase on a small LLaMA model after int8 conversion.
