
# 2508.19828v1 — Micro-Prefetch for Small-Batch GEMM & Low-Rank Attention Approximations

## Part 1: Efficient Micro-Prefetch for Small-Batch GEMM on CPUs

TL;DR

- Micro-prefetch strategies for small-batch GEMM on CPU cores to reduce cache-miss-induced latency spikes.

Why it matters

- On CPU inference for small batches, prefetching and tiling choices dramatically alter percentile latency.

Key takeaways

- Lightweight software prefetching at tile boundaries reduces tail latency with minimal overhead.
- Prefetch distance should be adaptive to observed L1/L2 miss rates.

Actions / Implementation steps for lightbulb

1. Add a tiny profiler to measure cache misses per attention/block kernel.
2. Implement configurable software-prefetch hints in kernels and a heuristic to pick prefetch distance.

Acceptance criteria

- Tail latency (95/99) improves on representative small-batch runs without increasing median runtime.
