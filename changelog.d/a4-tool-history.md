kind: A4 tool-call history through the chat template
---
When a request offers `tools` and the checkpoint's own chat template renders them, the conversation now reaches the template with the assistant's earlier `tool_calls` (arguments as an object, as `transformers` passes them) and each tool result's `tool_call_id` and `name`, not only `role` and `content`; before, a follow-up turn that carried a tool result rendered the call and its result as bare text. New `ChatTemplate::render_json_with_tools` takes HF-shaped message values; `render_with_tools` delegates to it and renders as before. Verified on a hand-written template (history reaches it; a history without tool turns renders unchanged) and by dropping the `tool_calls` conversion, which fails the test; not checked against a real model's template on a multi-turn tool conversation. A message's `name` is now passed to the template whenever the request supplies one (HF does the same).
